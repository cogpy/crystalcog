# Demo Scripts

This directory contains demonstration runner scripts for the CrystalCog project.

## Available Scripts

| Script | Description |
|--------|-------------|
| `demo_profiling_tools.sh` | Demonstrates profiling tools usage |

## Usage

From the repository root:

```bash
# Run profiling tools demo
./scripts/demos/demo_profiling_tools.sh
```
