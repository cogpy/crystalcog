# Crystal Examples

This directory contains demonstration scripts for the CrystalCog project.

## Available Demos

| File | Description |
|------|-------------|
| `demo.cr` | Basic CrystalCog demonstration |
| `demo_advanced_pattern_matching.cr` | Advanced pattern matching examples |
| `demo_advanced_reasoning.cr` | Reasoning system demonstrations |
| `demo_ai_integration.cr` | AI integration examples |
| `demo_attention.cr` | Attention allocation demonstrations |
| `demo_cogserver.cr` | CogServer usage examples |
| `demo_hypergraph_persistence.cr` | Hypergraph persistence examples |
| `demo_link_grammar.cr` | Link grammar integration examples |
| `demo_storage_backends.cr` | Storage backend demonstrations |

## Running Demos

From the repository root:

```bash
# Run basic demo
crystal run examples/crystal/demo.cr

# Run advanced pattern matching demo
crystal run examples/crystal/demo_advanced_pattern_matching.cr

# Run CogServer demo
crystal run examples/crystal/demo_cogserver.cr
```
